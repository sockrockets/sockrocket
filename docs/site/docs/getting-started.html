使用指南

三步建立连接。

先下载对应平台的发行包，导入你自己的订阅或节点，再验证系统代理是否工作。需要接管更多流量时再开 TUN。

Getting started

Three steps to a working connection.

Download the package for your platform, import your own subscription or nodes, then verify the system proxy. Enable TUN only when you need broader capture.

升级前请先退出旧版及其后台进程，避免端口或路由被重复占用。

2. 导入订阅或节点

桌面端：打开配置页，粘贴订阅 URL 并导入；或手动添加节点。支持节点链接以及 Clash、V2Ray、sing-box 订阅格式。

命令行：

sockrocket-cli --init config.yaml
# 编辑 config.yaml：填入 subscription URL 或 nodes
sockrocket-cli config.yaml
本软件不提供节点订阅与节点需自行准备。不要在 issue 或截图里贴出完整订阅地址、密码或 UUID。

3. 连接

  1. 选择一个节点，可先测延迟。
  2. 按需要选择规则 / 全局 / 直连。规则模式下，出口可以是全局节点、某一个节点，或一个节点分组。
  3. 点击连接。默认系统代理即可覆盖多数应用。
  4. 需要接管更多流量时，再启用 TUN，并按系统提示授权。

验证访问

curl -x socks5://127.0.0.1:1080 https://www.google.com -I
curl -x http://127.0.0.1:1087 https://www.google.com -I

默认监听：SOCKS5 127.0.0.1:1080，HTTP 127.0.0.1:1087。

Quit the old version and its background instance before upgrading.

2. Import a subscription or nodes

Desktop: paste a subscription URL and import, or add nodes manually. Node links plus Clash, V2Ray and sing-box formats are supported.

CLI:

sockrocket-cli --init config.yaml
# Edit config.yaml with your subscription URL or nodes
sockrocket-cli config.yaml
No nodes are bundledBring your own. Never paste full subscription URLs, passwords or UUIDs into issues or screenshots.

3. Connect

  1. Pick a node; latency test is optional.
  2. Choose Rule, Global or Direct. In rule mode an exit can be the global node, one node, or a node group.
  3. Connect. System proxy covers most apps.
  4. Enable TUN (and authorize) only when you need broader capture.

Verify

curl -x socks5://127.0.0.1:1080 https://www.google.com -I
curl -x http://127.0.0.1:1087 https://www.google.com -I

Defaults: SOCKS5 127.0.0.1:1080, HTTP 127.0.0.1:1087.

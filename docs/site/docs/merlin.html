Match the firmware platform, not the marketing name.

Install offline from Software Center on AsusWRT-Merlin. Wrong platform is the usual failure — especially hnd vs hnd_v8.

先刷出软件中心

插件在软件中心里离线安装。原版 AsusWRT-Merlin 没有这个菜单。带软件中心的固件在 KoolCenter 下载服务器，按机型进目录：

https://fw.koolcenter.com/

固件目录
梅林改版 3004.388KoolCenter_梅林改版固件_3004.388
梅林改版 3006.102KoolCenter_梅林改版固件_3006.102
华硕官改KoolCenter_华硕官改固件
更早的 3004.386KoolCenter_梅林改版固件_3004.386
  1. 打开和机型同名的目录。名称以路由器「系统管理 → 固件升级」里显示的型号为准。没有单独目录的联名版，用基础型号的目录。
  2. 下载该目录里日期最新的稳定固件。不要进入 alpha 或 beta。
  3. WebUI → 系统管理 → 固件升级，上传这个文件，等路由器自己重启。中途不要断电。
  4. 重启后菜单里会出现软件中心。再到系统设置打开 JFFS 和自定义脚本，然后按下面的平台安装 Sockrocket。

官改和梅林改版使用同一个平台包。平台看 CPU，不看刷的是哪一条固件线。

准备

  • Asus 路由器，固件为 AsusWRT-Merlin（建议 388.x+，含软件中心）。
  • 开启 JFFS 与自定义脚本（系统管理 → 系统设置）。
  • SSH 上执行 uname -m：armv7l 或 aarch64，用来对照下表。

安装步骤

  1. 从上表直接下载对应的 sockrocket-merlin-<platform>.tar.gz，并用 SHA256SUMS-merlin.txt 校验。
  2. 路由器 WebUI → 软件中心 → 离线安装，上传该包。
  3. 安装完成后打开 Sockrocket 入口（或 Softcenter 菜单中的模块页）。
  4. 在页面里添加订阅或节点，开启透明代理 / DNS 劫持（按需）。要让某个节点分组接管一部分流量，概览保持规则，再到分流规则里把出口选成这个分组。见 分流。

也可用 SSH 解压后执行 sh sockrocket/install.sh（可选传入平台标签）。日常更推荐软件中心。

装好之后，页面上有什么

  • 概览：启动或停止。启动会同时打开 DNS 接管和透明代理；运行中可以分别关掉。这里也能看到本次启动以来各节点的流量。
  • 节点：使用某一个节点，或新建节点分组。手动分组只保留一个节点。备用和测速可以多个，顺序只对备用有意义。
  • 订阅：更新订阅。近三个月的节点用量和订阅合计也在这里。合计是当前成员之和，不显示订阅地址。
  • 分流规则：给一组规则选出口（全局节点、单个节点或节点分组），检查某个网站会命中哪里，或添加默认停用的常用预设。
  • 网络与 DNS：默认 IPv4 兼容。只有固件已经有 IPv6 地址和 LAN 前缀时，再考虑双栈。

分组要接管流量，概览保持规则模式，并把分流规则的出口选成它。见 分流。

安装后注意

  • 默认 IPv6 模式为兼容：不依赖运营商是否开通 IPv6；只有固件已有 IPv6 时再考虑双栈。
  • 升级前备份配置，并确认 JFFS 空间足够。
  • 完整机型对照与故障排查见仓库长文（需要时再打开）：docs/merlin.md。

Flash a firmware that includes Software Center

The plugin is installed offline from Software Center. Upstream AsusWRT-Merlin does not add that menu. Firmware that does is on the KoolCenter download server, one folder per model:

https://fw.koolcenter.com/

LineDirectory
Merlin build 3004.388KoolCenter_梅林改版固件_3004.388
Merlin build 3006.102KoolCenter_梅林改版固件_3006.102
Asus official-modKoolCenter_华硕官改固件
Older 3004.386KoolCenter_梅林改版固件_3004.386
  1. Open the folder named like the model shown under Administration → Firmware Upgrade. A co-branded edition without its own folder uses the base model.
  2. Download the newest stable file in that folder. Leave alpha and beta alone.
  3. WebUI → Administration → Firmware Upgrade. Upload the file and wait for the router to reboot. Do not power it off.
  4. Software Center appears after reboot. Enable JFFS and custom scripts under System, then install the Sockrocket package for your platform below.

Official-mod and Merlin builds use the same platform package. The platform follows the CPU, not which firmware line you flashed.

Requirements

  • Asus router on AsusWRT-Merlin (388.x+ recommended) with Software Center.
  • JFFS and custom scripts enabled.
  • Run uname -m (armv7l or aarch64) and match the table below.

Install

  1. Download the matching package from the table. Check it with SHA256SUMS-merlin.txt.
  2. Router WebUI → Software Center → Offline install → upload the archive.
  3. Open the Sockrocket module and add your subscription or nodes.
  4. Enable transparent proxy / DNS hijack as needed. To send some traffic through a node group, stay in Rule mode and set that rule's exit to the group. See Routing.

What the pages do

  • Overview: start or stop. Start turns on DNS interception and transparent proxy together; either can be turned off while running. This page also shows bytes forwarded since this process started.
  • Nodes: use one node, or create a node group. A manual group keeps one node. Fallback and URL test can include several; order matters for fallback.
  • Subscriptions: update subscriptions. The last three calendar months are here too. A subscription total is the sum of its current nodes. Addresses are not shown.
  • Routing rules: set a rule group's exit to the global node, one node, or a node group. Check where a site would match, or add the built-in presets, which start disabled.
  • Network & DNS: compatibility is the default. Consider dual-stack only after the firmware already has an IPv6 address and a LAN prefix.

A group carries traffic only in Rule mode, and only after a rule's exit names it. See Routing.

After install

  • Default IPv6 mode is compatibility — no ISP IPv6 required.
  • Back up config and check JFFS space before upgrades.
  • Full model tables: docs/merlin.md.

Shadowsocks、VLESS、Hysteria2、Mieru 等协议支持表

协议TCPUDP说明
Shadowsocks是是AEAD / SS2022；ShadowTLS 仅 TCP
VMess是是仅 AEAD（alterId = 0）
VLESS是是TLS / WS / REALITY；Vision 见下
Trojan是是默认 TLS
TUIC v5是是原生 QUIC
Hysteria2是是原生 QUIC；混淆与端口跳跃未实现
AnyTLS v2是是原生 TLS 会话复用；UDP-over-TCP v2
Mieru v3实验性 / Experimental不支持 / NoTCP carrier · single fixed port · Clash / mierus://
WireGuard是是用户态，最多 64 个 Peer；UDP 需符合隧道 MTU

兼容边界

  • VLESS Vision：TLS 1.3 / REALITY TCP 与 XUDP；标准 flow 拒绝 UDP/443，便于客户端回退 TCP。
  • 当前源码已实现 HTTPUpgrade、gRPC 和 VLESS XHTTP；具体协议组合与参数限制见仓库协议文档，发行包以对应版本说明为准。
  • WireGuard：当前源码支持每节点最多 64 个 Peer；不支持 IP 分片、AmneziaWG 与系统接口脚本。
  • 默认校验证书；节点的 udp 开关也会限制 UDP。

更细的 Vision / AnyTLS / WireGuard 说明见仓库：docs/protocols.md。

梅林路由器 Mieru 协议支持与导入

Sockrocket 已加入实验性 Mieru v3 支持：TCP carrier、单一固定端口、标准握手、每条连接一个会话。可导入 Clash 节点或简单的 mierus:// 链接。当前不支持 UDP；Mieru 会同时关闭双向连接，因此不支持等待 TCP FIN 后才回复的目标服务。已完成 macOS 上与 Mihomo v1.19.31 的 TCP echo 测试，不能据此视为所有梅林机型均已验证。

使用前核对已安装版本的发行说明。完整实现与测试范围见协议支持文档。

梅林代理插件的协议与客户端兼容性

Shadowsocks、VMess、VLESS、Trojan 节点怎么选？

先按现有节点提供的协议和参数导入，再核对上表的支持范围。协议名称相同不代表每一种传输组合都支持；遇到不支持的参数应查阅发行说明，而不是直接删除参数尝试连接。

梅林路由器支持 Hysteria2、TUIC、AnyTLS 和 WireGuard 吗？

Sockrocket 的协议表包含这些协议，但应以所安装发行版及其限制为准。还要检查服务端配置、UDP 连通性和固件环境。安装教程负责固件选包，本页负责协议与传输兼容性。

VLESS REALITY 与 Vision 的支持范围是什么？

本页列出的 VLESS Vision 能力包括 TLS 1.3 / REALITY TCP 与 XUDP；标准 flow 拒绝 UDP/443。当前源码支持 VLESS XHTTP，但 Vision 不能叠加在 XHTTP 上；不支持的参数会明确拒绝。请核对节点的完整传输配置，不要只根据 VLESS 标签判断可用。

Limits

  • VLESS Vision: TLS 1.3 / REALITY TCP and XUDP; standard flow rejects UDP/443 for TCP fallback.
  • Current source supports HTTPUpgrade, gRPC and VLESS XHTTP; consult the repository protocol guide for supported combinations and release notes for installed packages.
  • WireGuard: up to 64 peers per node in current source; no IP fragmentation, AmneziaWG or OS interface hooks.

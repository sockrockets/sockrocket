协议一览

协议TCPUDP说明
Shadowsocks是是AEAD / SS2022；ShadowTLS 仅 TCP
VMess是是仅 AEAD（alterId = 0）
VLESS是是TLS / WS / REALITY；Vision 见下
Trojan是是默认 TLS
TUIC v5是是原生 QUIC
Hysteria2是是原生 QUIC；混淆与端口跳跃未实现
AnyTLS v2是是原生 TLS 会话复用；UDP-over-TCP v2
WireGuard是是用户态单 Peer；UDP 需符合隧道 MTU

兼容边界

  • VLESS Vision：TLS 1.3 / REALITY TCP 与 XUDP；标准 flow 拒绝 UDP/443，便于客户端回退 TCP。
  • gRPC / XHTTP 等未实现的传输会明确拒绝，不会悄悄改成裸 TCP。
  • WireGuard：暂不支持多 Peer、IP 分片与配置脚本。
  • 默认校验证书；节点的 udp 开关也会限制 UDP。

更细的 Vision / AnyTLS / WireGuard 说明见仓库：docs/protocols.md。

ProtocolTCPUDPNotes

AnyTLS v2YesYesNative TLS reuse; UDP-over-TCP v2
WireGuardYesYesUserspace, one peer; UDP must fit tunnel MTU

Limits

  • VLESS Vision: TLS 1.3 / REALITY TCP and XUDP; standard flow rejects UDP/443 for TCP fallback.
  • Unsupported transports such as gRPC / XHTTP are rejected explicitly.
  • WireGuard: no multi-peer, IP fragmentation or profile scripts yet.

Details: docs/protocols.md.

基础

  • listen_addr / socks_port / http_port：本机代理监听。
  • subscriptions：订阅列表；nodes：手动节点；active_node：当前出口。
  • proxy_mode：rule（规则）、global、direct。

DNS 与 IPv6（Merlin）

  • IPv4 兼容（推荐）：不确定运营商是否开通 IPv6 时保持此项。代理走 IPv4；固件若已开 IPv6，则拒绝外网 IPv6 转发。
  • 双栈（可选）：仅当固件已拿到 IPv6 地址与 LAN 前缀时再开。做不完会保住 IPv4 代理并自动重试。
  • 在 Softcenter「网络与 DNS」页保存时，运行中的服务会就地重新应用防火墙，不会无故重启代理；服务停止时只保存配置。

规则顺序

规则模式下匹配顺序是：设备目的规则 → 共享规则（含国内直连）→ 设备兜底 → 全局兜底。出口可以是全局节点、某一个节点，或一个节点分组。分组怎么生效，见 分流。

用量

概览统计的是本次进程启动以来各节点转发的流量，重启后重新累计。订阅页按自然月显示最近三个月：每个节点一行，包括手动节点和直连。订阅合计是当前属于它的节点之和；直连、以及还没有归属订阅的节点，只出现在节点表里。页面只显示订阅名称，不显示地址。

命令行最小示例

sockrocket-cli --init config.yaml
sockrocket-cli config.yaml

完整字段、健康检查、分组等见仓库：docs/configuration.md。

Basics

  • listen_addr / socks_port / http_port: local listeners.
  • subscriptions, nodes, active_node: sources and the selected exit.
  • proxy_mode: rule, global, or direct.

DNS & IPv6 (Merlin)

  • Compatibility (recommended) when ISP IPv6 is unknown: IPv4 proxy; reject forwarded external IPv6 only if firmware IPv6 is on.
  • Dual-stack (optional) after firmware already has an IPv6 address and LAN prefix. Incomplete setup keeps IPv4 and retries.
  • Saving Network & DNS reapplies the firewall in place without restarting a running proxy.

Rule order

Device destination rules → shared rules (including China direct) → device final → global final. An exit can be the global node, one node, or a node group. See Routing for when a group takes effect.

Traffic

The overview counts bytes forwarded since this process started and starts over after a restart. The subscriptions page shows the last three calendar months per node, including manual nodes and Direct. A subscription total is the sum of nodes that currently belong to it. Direct traffic and nodes with no subscription stay in the node table. The page shows subscription names only.

CLI

sockrocket-cli --init config.yaml
sockrocket-cli config.yaml

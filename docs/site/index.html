Features

Built for daily use,
not demo day.

Through-proxy latency, real routing, and a Merlin plugin that shares the same engine as the desktop client.

⚡

Warm through-proxy tests

Node ranking measures exit-side RTT on a warm path — what browsing feels like, not a fake TCP ping to server:port.

🧭

Smart routing

Domain, GeoIP, and CIDR rules. System proxy for typical apps; TUN when something ignores the OS proxy.

🔏

TLS fingerprint craft

Patched rustls (craftls) with REALITY and browser-like ClientHello — built for hostile networks.

📡

Subscriptions

Clash, V2Ray / VMess, SingBox URLs. Auto-detect, update, dedupe, batch test.

🖥️

GUI + CLI

Native GPUI desktop app and a lean CLI for headless or scripted setups.

🛰️

LAN-wide Merlin

Official AsusWRT-Merlin package: one musl binary, Web UI, iptables/DNS, hot-reload node switch.

asuswrt-merlin · koolcenter

Same engine on the router.

What works in the GUI works on Merlin — transparent proxy for every device on your LAN.

  • Platform packages: arm64 (hnd_v8), armv7 soft/hard float
  • Hot-reload set_node without tearing down listeners
  • Through-proxy probe concurrency capped for router stability

Quick start

Up in under a minute.

Grab a release binary. Default SOCKS5 :1080 · HTTP :1087.

# macOS — open DMG, drag Sockrocket to Applications
open sockrocket-macos-aarch64.dmg

# Linux — extract + install (icons / app menu)
tar xzf sockrocket-linux-x86_64.tar.gz
./Sockrocket-*-linux-x86_64/install.sh

# Windows — extract ZIP, run Sockrocket.exe
sockrocket-cli --init config.yaml
# edit config.yaml, then:
sockrocket-cli config.yaml
# Install .tar.gz from Releases via Software Center / koolcenter
# or copy to /tmp and install from Merlin Web UI
# see docs/merlin.md

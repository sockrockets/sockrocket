AnyTLS 与 WireGuard 已接入桌面端、CLI 和 Merlin。以下描述当前源码，下载页中的发行包以各版本发布说明为准。

TLS

AnyTLS v2

原生 TLS 连接、会话复用与 UDP-over-TCP v2。支持分享链接、Clash 和 sing-box 导入，默认验证服务器证书。

已通过独立服务端 TCP / UDP 互通测试。

UDP

WireGuard

原生用户态隧道，每个节点对应一个 Peer。支持预共享密钥、隧道内 DNS，以及 WireGuard 配置文件导入。

无需额外系统网卡；UDP 单包需符合隧道 MTU。

兼容性边界：Vision、gRPC / XHTTP 尚未实现，会明确拒绝相关配置。WireGuard 暂不支持多 Peer、IP 分片和配置脚本。

FAQ

连接之前，先了解这些。

Sockrocket 提供节点或订阅吗？

不提供。Sockrocket 是代理客户端与内核，需要你自行配置可用的节点或订阅。

系统代理和 TUN 有什么区别？

系统代理用于遵循系统代理设置的应用。TUN 接管更多网络流量，需要管理员权限和可用的驱动环境。避免同时运行多个 TUN 或 VPN。

Merlin 安装包应该怎么选？

根据固件平台标签和 CPU 架构选择，不要只根据路由器名称猜测。安装前阅读 Merlin 指南，升级前备份配置并检查 JFFS 空间。

反馈问题时需要提供什么？

提供软件版本、操作系统或固件版本、触发步骤和脱敏日志。删除完整订阅 URL、节点地址、密码、UUID、令牌、二维码和个人路径。

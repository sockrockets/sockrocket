源码能力 · 以发行说明为准

AnyTLS 与 WireGuard 已接入桌面端、CLI 和 Merlin。以下描述当前源码，下载页中的发行包以各版本发布说明为准。

TLS

AnyTLS v2

原生 TLS 连接、会话复用与 UDP-over-TCP v2。支持分享链接、Clash 和 sing-box 导入，默认验证服务器证书。

已通过独立服务端 TCP / UDP 互通测试。

UDP

WireGuard

原生用户态隧道，每个节点对应一个 Peer。支持预共享密钥、隧道内 DNS，以及 WireGuard 配置文件导入。

无需额外系统网卡；UDP 单包需符合隧道 MTU。

兼容性边界：VLESS Vision 支持 TLS 1.3 / REALITY TCP 与 XUDP（标准 flow 拒绝 UDP/443）；gRPC / XHTTP 尚未实现，会明确拒绝相关配置。WireGuard 暂不支持多 Peer、IP 分片和配置脚本。

路由器上已经能用

分组、出口、用量，各管一件事。

这些是后来加进 Merlin 页面的能力。桌面端共用同一套内核；下面按路由器上的操作来写。

分组

节点分组

手动选择只用一个节点。备用按列表顺序尝试，五分钟内从上次连上的成员开始。测速把更快的握手保留五分钟，顺序不决定赢家。

出口

规则出口

全局节点跟着顶部当前节点走。单个节点钉住不动。节点分组是独立出口，换成员不改变全局节点。只有规则模式会看这些出口。

用量

流量统计

概览是本次进程启动以来各节点的转发量，重启后重新累计。订阅页是最近三个自然月。订阅合计等于当前属于它的节点之和，不显示订阅地址。

检查

去向检查

在分流规则里输入网站，看命中哪一条、走哪个出口。它只解释已保存的规则，不发起代理连接，也不保存查询。

预设

常用规则预设

AI、海外视频、Telegram 网页、开发工具、Apple、Microsoft 和国内站点。添加后先是停用，由你再打开。名单不是这些服务的全部地址。

网络

IPv6 与开关

默认保持 IPv4 兼容，不要求运营商开通 IPv6。启动会同时打开 DNS 接管和透明代理；运行中可以分别关掉。打开透明代理时会一并打开 DNS 接管。

FAQ

连接之前，先了解这些。

Sockrocket 提供节点或订阅吗？

不提供。Sockrocket 是代理客户端与内核，需要你自行配置可用的节点或订阅。

系统代理和 TUN 有什么区别？

系统代理用于遵循系统代理设置的应用。TUN 接管更多网络流量，需要管理员权限和可用的驱动环境。避免同时运行多个 TUN 或 VPN。

Merlin 安装包应该怎么选？

对照下载表里的常见机型。联名版跟基础型号用同一个包。IPQ53xx 先看 uname -m：armv7l 用 ipq32，aarch64 用 ipq64。安装前阅读 Merlin 指南，升级前备份配置并检查 JFFS 空间。

反馈问题时需要提供什么？

提供软件版本、操作系统或固件版本、触发步骤和脱敏日志。删除完整订阅 URL、节点地址、密码、UUID、令牌、二维码和个人路径。

分组建好了，为什么流量没走它？

分组不会自己接管。概览要停在规则模式，再到分流规则里把出口选成「分组 · 名字」。直连和拒绝不会被这次修改改掉。全局和直连模式不看分组。

订阅用量为什么和单个节点对不上？

订阅合计是当前属于这个订阅的节点相加。直连、以及没有归属订阅的节点，只出现在节点表里。页面不显示订阅地址。

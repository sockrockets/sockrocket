# v0.0.12

## TCP

- New writes use only the peer window left after accounting for bytes in flight.
- ACK validation runs before retransmission queues, send windows and payload credits are changed, so an ACK for unsent bytes cannot discard pending data.

## Connection memory and probes

- Nested task-local context wrappers return their scoped futures directly, avoiding duplicated future storage in TUN connection tasks.
- Completed SOCKS UDP tasks are reclaimed periodically without waiting for another client packet. Resource quotas remain charged until the flow and worker have both released them.
- Concurrent URL-test requests share node selection, with per-group and global probe limits; each request still opens its own destination stream.
- Cancelling a Reality probe clears its in-flight registration and wakes waiting connections without losing completion notifications.

## Local Merlin builds

- Local ARM64 builds compile C dependencies with Zig and perform the final link with Rust's bundled musl runtime.
- Builds verify allocator symbols before stripping and preserve a matching symbol file. The C wrapper rejects direct Rust library linking through the old Zig path.
- The build guide records the reproduced Zig allocator retention mechanism, artifact verification and the distinction from the existing cross-based Actions builds.

The allocator comparison confirms a retention mechanism; sustained live validation is still needed before attributing all historical memory growth or throughput problems to it.

# v0.0.5

## IPv4 compatibility and optional dual-stack

- Compatibility remains the default. IPv6 DNS and transparent IPv6 routing run only when dual-stack is selected.
- Saving DNS settings does not start a stopped proxy. New lookups use the saved policy, and the current proxy and TUN state stay as they were.
- A WAN reconnect restores DNS hijack. If dual-stack setup fails, IPv4 proxying and the compatibility guard stay in place.

## Proxy groups

- Fallback and url-test groups remember a working member and retry from there.
- A Clash import that names a policy this config does not have stays on the proxy path.

## Faster tunnels

- Local sockets no longer pin a 64 KiB send or receive buffer, so the kernel can grow the TCP window.
- The TUN stack negotiates window scaling. One flow can use a wider window, and the shared window narrows again as more TCP sessions open.

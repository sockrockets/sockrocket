## Sockrocket v0.1.4

- Merlin checks for updates over its running local SOCKS proxy when the direct GitHub lookup stalls. Both the WebUI and the installation worker use the same lookup.
- On GitHub API server errors, Merlin can also resolve the release and verify the package size through the official release page.
- Merlin builds install cross 0.2.5 from crates.io. The standalone Merlin ARM64 binary is published as `sockrocket-cli-merlin-aarch64` so the Linux desktop CLI keeps its own download and checksum.

For RT-AX86U Pro, use `sockrocket-merlin-hnd_v8.tar.gz` and verify it against `SHA256SUMS-merlin.txt`.

## Merlin rule management

- Keep existing proxy connections open when enabling or disabling a rule group, deleting a rule or group, saving bulk edits, and importing rules from a URL. New connections use the updated routing policy after reload.
- Show downloaded rules in the editable preview. Confirmation appends them to the selected group and reports additions and duplicates. Importing the same list again skips duplicates.
- Handle atomic configuration saves on router filesystems with coarse timestamps. Update the IPv4 device scope for domestic direct acceleration when a rule change affects it.

## Merlin settings

- Check that the selected node, subscription, or rule group still matches what the user reviewed before applying changes.
- Protect configuration drafts and show which settings have been saved while a reload is pending.

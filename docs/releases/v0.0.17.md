# v0.0.17

## Proxy and TUN performance

- Add bounded, single-use Vision preconnections while retaining concrete TLS streams for direct-copy transitions. Latency probes do not prewarm connections.
- Batch TUN TCP writes within MSS, MTU, peer-window and memory-budget limits; share segment data between transmit and retransmission queues.
- Reduce packet-queue locking when no writer is waiting, improve ACK-prefix cleanup and preserve partial-write/backpressure semantics.
- Aggregate traffic ledger updates outside the per-I/O accounting path while preserving live counters and cancellation-safe persistence.
- Cache desktop node-list search and sorting metadata.

## DNS and compatibility

- Coalesce identical concurrent raw DNS queries while separating transaction IDs, EDNS, flags, upstream choices and direct/proxy exits.
- Fix last-caller cleanup of shared DNS queries during concurrent completion and cancellation.
- Retain main's startup MTU selection, private endpoint logging and CI/package fixes.

## Build and validation

This release retains opt-level=3, thin LTO and the existing TLS dependency defaults. The separate size experiments are not included. Router builds retain the canonical musl linker and allocator checks.

Validation before tagging: 820 runtime tests passed (21 opt-in tests ignored); Vision interoperability passed in warmed and unwarmed modes; ARM64 musl allocator verification passed with zero Zig SMP symbols. Installer/RPC checks, 11 update tests, Web UI update-state tests and 44 stability scenarios passed. Desktop compilation and all 9 desktop logic tests passed. Short network samples do not guarantee higher speed on every connection. Session admission and system-memory protection still apply under heavy LAN traffic.

# v0.0.18

## Merlin runtime reliability

- Read and parse each reload once so node, routing and legacy DNS settings belong to the same configuration revision.
- Reject enabled rules with unknown types, invalid patterns or unrecognized targets before replacing the running configuration.
- Expose configuration application state in the API and WebUI: validating, rejected, applied, restart required, network policy pending or failed. A late policy completion cannot acknowledge a newer revision.
- Preserve existing group selection, pinned-node rules and historical traffic when migrating to versioned node identities. Old ambiguous identities retain their previous first-node selection. New identities include TLS/SNI, Reality short IDs, WebSocket headers, ShadowTLS credentials and UDP capability; display metadata remains excluded.
- Migrate references against the old catalog before a subscription update removes or replaces its nodes. Missing members continue to fail closed.

## CPU and binary size

- Build one temporary node index for a group snapshot rather than repeatedly serializing identities for every member lookup. This reduces configuration-processing work, not network round-trip time.
- Use receive-only certificate codec providers for client fingerprints. The full providers remain available, and both variants call the same decompression functions. Advertised algorithms and certificate verification are unchanged.
- In an isolated ARM64 comparison with identical thin-LTO / opt-level=3 settings, the codec change reduced the stripped binary from 15,231,672 to 13,962,584 bytes (8.33%). These are comparison artifacts, not a promise about every release package or network workload.
- Keep optimization level, relay buffers, TCP windows and pool limits unchanged. No size-oriented optimization level or executable packer is enabled.

## Build and validation

- Route ARM64 Actions builds through a shared entry point that verifies actual musl allocator symbols before stripping. ARMv7 continues using its existing cross build; the ARM64 verifier is not applied to ARMv7.
- Local core/CLI regression: 816 passed, 21 opt-in tests ignored. Independent warmed/unwarmed Vision interoperability: 2 passed. Certificate decoder, reference migration and traffic-history preservation tests are included.
- Merlin validation includes 45 stability scenarios, installer/RPC checks, 11 updater scenarios, atomic DNS configuration and WebUI tests.

Configuration references written by this release use a new identity format. Retain the pre-upgrade configuration and traffic-history backup when preparing a rollback to an older binary.

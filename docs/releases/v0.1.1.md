## Sockrocket v0.1.1

Routing and Merlin UI polish on top of v0.1.0.

### Highlights

- **Proxy mode on Merlin** — Rule / Global / Direct (same model as the desktop client); WebUI Softcenter page stays in sync on deploy
- **Unified batch rules** — Clash-style `TYPE,pattern,ACTION` for group edit / paste
- **China Direct accuracy** — refreshed built-in CN CIDR merge; Rule mode order keeps geoip:CN ahead of Final
- **Rules UX** — rule groups / scenes / batch import helpers shared by GUI and CGI

### Desktop

Same artifact names as v0.1.0 (`sockrocket-*-{platform}.*` and matching CLI binaries).

### Merlin

Same platform packages (`sockrocket-merlin-<platform>.tar.gz`). Prefer Software Center offline install; after upgrade confirm `sockrocket.sh status` shows running.

Guide: https://github.com/sockrockets/sockrocket/blob/main/docs/merlin.md

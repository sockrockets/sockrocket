# v0.0.7

## Traffic

- The overview shows each node's usage since this process started.
- The subscriptions page shows the last three calendar months for each node, and a total for each subscription.
- A subscription total adds up the nodes that currently belong to it. Direct traffic and nodes without a subscription stay in the node table.
- Subscription addresses are not shown in the usage tables.

## Rules

- The rule diagram sends traffic into the first stage only. Later stages are reached when earlier stages miss.

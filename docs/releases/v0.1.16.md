## Sockrocket v0.1.16

- In the default China-direct policy, check the configured direct DNS servers for a mainland address when the primary resolver returns only overseas addresses. The check uses the requested address family and sends the queried name to the direct DNS provider.
- Preserve explicit domain routes on shared CDNs. Restore the domain and address family of Fake-IP destinations for TUN and SOCKS5 TCP and UDP traffic.
- Dial the addresses that matched an IP-based direct rule. Cache empty address answers and briefly back off failed optional DNS checks to avoid delaying repeated connections.

## Sockrocket v0.1.0

Cross-platform Rust proxy client: native GUI, CLI, and AsusWRT-Merlin plugin. Same protocol engine on desktop and router.

### Desktop

| Platform | GUI | CLI |
|----------|-----|-----|
| Linux x86_64 | `sockrocket-linux-x86_64.tar.gz` | `sockrocket-cli-linux-x86_64` |
| Linux aarch64 | `sockrocket-linux-aarch64.tar.gz` | `sockrocket-cli-linux-aarch64` |
| macOS Intel | `sockrocket-macos-x86_64.dmg` | `sockrocket-cli-macos-x86_64` |
| macOS Apple Silicon | `sockrocket-macos-aarch64.dmg` | `sockrocket-cli-macos-aarch64` |
| Windows x86_64 | `sockrocket-windows-x86_64.zip` | `sockrocket-cli-windows-x86_64.exe` |

Default listeners: SOCKS5 `127.0.0.1:1080` · HTTP `127.0.0.1:1087`.

**macOS Gatekeeper:** if the app is blocked, run `xattr -cr /Applications/Sockrocket.app` then open again (unsigned builds).

### Merlin (LAN-wide)

Select the exact router model, hardware revision and firmware ABI in the [model-to-package guide](https://github.com/sockrockets/sockrocket/blob/v0.1.0/docs/merlin-models.md). The same guide is included in each archive and as a release asset.

| Example model | Firmware ABI | Software Center offline package |
|---|---|---|
| RT-AC88U (Koolshare 384/386) | ARMv7 · soft-float | `sockrocket-merlin-arm.tar.gz` |
| RT-AX58U | ARMv7 · hard-float | `sockrocket-merlin-hnd.tar.gz` |
| RT-AX88U / RT-AX88U PRO | AArch64 | `sockrocket-merlin-hnd_v8.tar.gz` |
| RT-AX89X | ARMv7 · hard-float | `sockrocket-merlin-qca.tar.gz` |
| TX-AX6000 | AArch64 | `sockrocket-merlin-mtk.tar.gz` |
| ZenWiFi BD4 | ARMv7 · hard-float | `sockrocket-merlin-ipq32.tar.gz` |
| TUF-BE6500 | AArch64 | `sockrocket-merlin-ipq64.tar.gz` |

Verify the archive against `SHA256SUMS-merlin.txt`, then upload it through Software Center → Offline install. The legacy ARM package now carries the `arm386` marker required by the 384/386 installer.

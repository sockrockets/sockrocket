## Sockrocket v0.1.7

- The Merlin ARM64 CLI now fits within 11,000,000 bytes. The build checks the stripped executable before packaging.
- Fresh ARM64 installs fit in 13 MB of free persistent storage on the tested standard Merlin and Software Center layouts. The installer checks the filesystems used for the plugin and its settings page. The archive and extracted files also need temporary space under `/tmp`.
- Once v0.1.7 is installed, online updates measure the space needed for the new files and rollback data before stopping the proxy. Updates and rollbacks preserve a manually stopped proxy and can restore the previous executable after an interruption.
- If v0.1.6 declines an online update because space is low, use the v0.1.7 offline package for your router platform to run the new installer.

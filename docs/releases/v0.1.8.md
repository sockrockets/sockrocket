## Sockrocket v0.1.8

- Refresh saved Clash subscriptions after upgrading to pick up provider-specific node DNS. Sockrocket requests the Clash profile for subscriptions marked as Clash and automatic links with `clash=1`. Providers that reject that profile can still serve the original request.
- Node connections and latency checks use the subscription’s dedicated endpoint DNS. When a profile enables DNS and supplies only ordinary nameservers, Sockrocket uses them for node lookups. Saved node selections, group memberships and routing rules follow unambiguous DNS changes on refresh.
- VMess AEAD nodes using AES or ChaCha now mask chunk lengths by default for Clash Meta compatibility. WebSocket and HTTPUpgrade connections retain their configured Host when the node address resolves to an IP.
- The Merlin management page requests traffic statistics for the current view and skips overlapping refreshes. The ARM64 build checks that the stripped router executable fits within 11,100,000 bytes.

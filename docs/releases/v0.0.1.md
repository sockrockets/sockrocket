# v0.0.1

## Merlin routing rules

- Retain the integrated light settings interface.
- Add numeric priorities for individual rules, new rules and batch/group edits. Higher values match first; ties preserve configuration order. Final rules remain after built-in China-direct routing.
- Display effective rule order and priority, with search, action/status filters and pagination.
- Add in-place rule editing. Stale edit, move and delete requests are rejected instead of modifying another rule.
- Reject invalid batch input without partial saves. Preserve group metadata and priorities when no replacement value is supplied.
- Preserve drafts after validation or request failures and show when applying changes restarts a running service.

## TUIC compatibility

- Recognize the `insecure` URI alias, decode credentials, and preserve ALPN when sharing nodes.
- Import `pcs` certificate SHA-256 pins and enforce them against the leaf certificate, with cryptographic TLS handshake signature checks. Wrong pins fail closed.
- Preserve pins through local configuration, share links and Clash export/import; include trust settings in TUIC deduplication identity.
- Handle empty ALPN lists safely without panicking.

## macOS system proxy

- Verify committed proxy preferences with a fresh read-only session, without requesting an unauthorized write lock that could incorrectly trigger rollback.
- Configure HTTP and HTTPS for the HTTP listener without advertising that port as a SOCKS proxy. Restore the previous per-protocol settings through the ownership journal.
- Show a visible setup failure when the local tunnel is reachable but the system proxy cannot be enabled.

## Validation

- Cover priority bounds, persistence, ordering, stale requests, atomic batch changes and disabled group metadata with CLI regressions.
- Accept both EOF and Windows connection-reset behavior when testing immediate rejection of excess API connections.
- Keep local credentials, runtime diagnostics, private subscription data and preview artifacts outside release packages.

Includes the native protocols and compatibility limits documented in the [protocol support matrix](../protocols.md).

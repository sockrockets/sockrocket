# v0.0.15

## AnyTLS and TLS compatibility

- Support legacy AnyTLS peers without requiring v2 acknowledgements. Process idle-session heartbeats, reuse newer sessions first, and retain bounded server error messages.
- Use the Chrome 133 Auto profile selected by Mihomo v1.19.31 / uTLS v1.8.8 for ordinary TLS connections. Generate real X25519MLKEM768 and X25519 shares, modern ALPS and randomized ECH GREASE. Preserve certificate validation, pins, explicit ALPN and the classic `chrome112` / `chrome108` profiles. ECH GREASE does not encrypt SNI.

## Subscription endpoint DNS

- Preserve Clash `dns.proxy-server-nameserver` per imported node, including independent bootstrap settings, and use it for proxy connections and node probes.
- Keep the original TLS identity while resolving endpoints dynamically. Missing or empty policies retain the existing resolution path; explicit policy failures do not fall back to system DNS.
- Support UDP, TCP, DoT and DoH endpoint syntax. Unsupported resolver forms are rejected explicitly; see `docs/subscription-server-dns.md` for limits.

## Merlin updates and latency probes

- Add complete plugin self-updates with recovery and storage checks. Compress rollback backups and budget the actual update space.
- Run complete node-latency batches in background jobs with concurrent probes and recoverable progress.

## Validation and known limits

- The merged main CI passed before this version bump. Core/CLI regressions, handshake wire and crypto tests, independent AnyTLS TCP/UDP/session-reuse interoperability, and ARM64 musl allocator verification passed.
- The optional independent Vision large-transfer test still exhibits intermittent resets on the unchanged baseline. This release does not claim to resolve that separate issue.
- Live node HTTP/HTTPS checks passed on a controlled direct path. An additional proxy hop can affect handshake compatibility; these results do not guarantee every chained-proxy path.
- No real node credentials, subscription URLs or private resolver URLs are included.

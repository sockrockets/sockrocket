# v0.0.13

## Subscription downloads

- Download through three direct workers and, when available, three local SOCKS proxy workers, for at most six concurrent requests per subscription.
- Accept the first response that parses into usable nodes and cancel the remaining requests and retry timers. HTTP errors and invalid content on one route no longer abort a valid download on another.
- Allow each worker an initial request and up to three retries for HTTP or transport failures, with 200/400/800 ms backoff. All workers share a 30-second deadline; each decoded response remains limited to 8 MiB.
- Desktop imports and refreshes use the running application's SOCKS listener when available, and avoid multiplying retries through an additional UI retry loop.
- Preserve saved nodes on a failed refresh and keep private subscription URLs out of transport errors.

## Validation

- Core and CLI regression suites: 689 passed, 0 failed, 15 intentionally ignored.
- GUI compilation check passed.
- Local integration tests verify six simultaneous requests, cancellation of all five losing connections, retry limits, and response size limits.

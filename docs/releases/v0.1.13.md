## Sockrocket v0.1.13

- On Merlin routers, repeated outbound probe failures now keep the configured proxy and DNS rules in place. The status page reports when the proxy endpoint cannot be reached.
- If the management interface stops responding during a save, the editor keeps the draft and asks the user to reconnect using the router's LAN IP and check whether the configuration was saved.
- Service control commands now have a timeout so a stuck restart cannot hold the save request open indefinitely.

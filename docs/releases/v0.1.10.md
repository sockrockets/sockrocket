## Sockrocket v0.1.10

- Add experimental Mieru v3 TCP support for a single fixed server port and the standard handshake. Import a Clash node or a `mierus://` link, or enter the node in the Merlin Software Center.
- Clash import skips Mieru entries that require UDP-only operation or certificate pinning. Other supported entries in the same subscription remain available.
- A TCP echo test passed against Mihomo v1.19.31 on macOS. Destinations that wait for a TCP half-close before replying are unsupported.

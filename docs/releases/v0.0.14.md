# v0.0.14

## DNS and domain routing

- Resolve direct destinations with the direct DNS policy while preserving independent proxy and DNS bootstrap lookups.
- Recover explicit domain rules from a bounded TLS ClientHello prefix for otherwise unidentified TCP 443 connections. Preserve rule order and replay the original bytes without decrypting application traffic.

## TCP reliability

- Preserve overlapping retransmission tails and reordered payload, including sequence wrap and ordered FIN delivery.
- Use a connection-level retransmission timer with RTT estimation, capped backoff, and separate fast-retransmit and timeout budgets.
- Retry owned payload even when new-write credit is exhausted, and probe closed receive windows without consuming data-retry credit.
- Process fresh acknowledgements carried by duplicate payload and release buffer reservations on acknowledgement or failure.
- Keep existing session capacity limits unchanged.

## Privacy and validation

- TLS prefix inspection remains bounded to 4 KiB and 300 ms in memory, with no new capture files or external reporting.
- Core and CLI regression suites: 723 passed, 0 failed, 15 intentionally ignored.
- Vendored TCP stack unit suite: 21 passed. Targeted TCP regressions: 30 passed (included in the core suite).
- ARM64 musl release build and allocator verification passed with the release version; no Zig SmpAllocator symbols were present.

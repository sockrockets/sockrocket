## Sockrocket v0.1.9

- The Merlin Network & DNS page now accepts custom Hosts entries. Enter one IP address and exact hostname per line. IPv4 and IPv6 answers follow the configured address policy.
- Select Save and Apply to add or remove mappings while the proxy keeps running. When local DNS records change, Merlin restarts its DNS forwarder automatically. DNS rebind protection stays enabled for upstream responses.

# v0.0.8

## Merlin

- On Merlin 3006, only the main LAN dnsmasq uses Sockrocket's private upstream. Guest and SDN instances keep the firmware resolver.
- If the firmware returns before its dnsmasq hook runs, the service applies that same main-config edit itself instead of restarting DNS in a loop.
- A failed outbound check no longer restarts DNS every few seconds.
- Timed-out QUIC associations on the TUN path answer with port unreachable so clients can fall back to TCP.
- Public proxy endpoints leave directly, before device traffic is marked.

## Routing

- Leigod, NN, and Chiphell resolve through domestic DNS and stay direct, so a proxied login is not treated as an overseas client.

## Privacy

- Commit and tag identity rules, local file permissions, and what not to share are written in the privacy note.

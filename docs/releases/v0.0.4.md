# v0.0.4

## Merlin rule state and routing diagram

- Keep the rule list and routing diagram on the same ordered configuration snapshot, including priorities, disabled groups and mixed enabled/disabled rules. Only enabled rules contribute diagram exits.
- Highlight the actual matched group and exit when checking a destination. Clicking a group filters its corresponding rules; configuration changes invalidate stale filters and trace results.
- Keep rule controls locked through save, apply and status refresh. Reject stale responses, report invalid configurations, and distinguish saved settings from settings that failed to apply.
- Use the first available node when no explicit active node is selected, matching the running service's default behavior.

## Network controls

- Explicit Start enables DNS interception and TUN together. Stop displays both as off after network cleanup.
- Allow users to turn DNS interception and TUN off independently while running. Enabling TUN also enables DNS interception; internal restarts preserve the user's choices.
- Wait for fresh service status before unlocking network controls, and prevent older background responses from overwriting the latest action.

## Validation and upgrade

- Passed 63 CLI regression tests, 63 lifecycle assertions and five Web UI suites covering network controls, routing diagrams, presets, transport and subscription jobs.
- CLI Clippy, formatting checks and ARM64 musl release compilation passed locally. Router testing confirmed Stop cleanup and explicit Start defaults; independent network controls were also verified.
- Install the complete package through Software Center. Private configurations, subscription URLs, node credentials, local diagnostics and test files are excluded from installation packages.

## Sockrocket v0.1.5

- Release builds use Rust 1.99.1, optimization level 3, fat LTO, one code generation unit, stripped symbols and panic unwinding.
- Merlin can recover its controls after an interrupted or offline rollback.
- Device routing supports global defaults that follow the selected node.
- Native proxy support includes VLESS encryption, legacy VMess and Shadowsocks TCP plugins.

Use the HND package for 32-bit Broadcom HND firmware. The RT-AX86U Pro uses the HND v8 package.

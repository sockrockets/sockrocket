## Sockrocket v0.1.2

Subscription management polish on top of v0.1.1.

### Highlights

- **Rename subscriptions** — desktop Config list (click name / ✎) and Merlin WebUI Rename; display name only, URL and nodes unchanged
- **macOS TUN elevation** — enabling TUN prompts for administrator approval and relaunches elevated (same idea as Windows UAC); utun name is assigned by the kernel so existing system `utun` units do not block create
- **Rule-mode China direct by IP** — Fake-IP path runs resolve-then-`geoip:CN` on a clean upstream; mainland answers get real IPs (LAN direct) instead of depending only on a short domain list
- Includes the v0.1.1 CI rustfmt/clippy fixes on the release tip

### Desktop

Same artifact names as prior 0.1.x releases. On macOS, TUN mode requires approving the system authentication dialog.

### Merlin

Same platform packages (`sockrocket-merlin-<platform>.tar.gz`). After upgrade, confirm `sockrocket.sh status` shows running. Rule mode domestic direct needs this build on the router (resolve-then-geoip in DNS).

Guide: https://github.com/sockrockets/sockrocket/blob/main/docs/merlin.md

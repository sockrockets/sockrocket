# v0.0.10

## TUN

- Retransmission deadlines follow the packet timer, and a flow that exhausts them is released.
- An abandoned handshake times out on its own, separate from an established connection's idle time.
- An idle half-closed relay is bounded while an active transfer keeps running.

## Merlin

- Health checks, DNS recovery, and TCP diagnostics stay available when the proxy path is degraded.
- Subscription import no longer waits on a slow fetch before the saved nodes can be used.
- Outbound health speaks HTTP to the local proxy. Stock firmware curl has no proxy support, so a failed curl invocation is not treated as a dead node.
- A new process drops the previous run's probe failure and switch history. A successful probe clears the stored error.

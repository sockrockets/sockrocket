# v0.0.16

## Merlin self-update fixes

- Install the DNS template under the filename expected by the service controller.
- Compress backups of the plugin and configuration; restore both on rollback.
- Permit one recovery process at a time and retain backups when recovery health checks fail.
- Block configuration changes during updates and wait for existing configuration transactions before taking the backup.
- Validate old configurations with the candidate executable before installation.
- Report final success, rollback, or recovery failure in the Web UI, including reconnecting after API restart.

## Automatic TUN MTU

- Select MTU at startup and apply it consistently to the TUN interface, userspace stack and TCP MSS.
- Handle BusyBox silent path-MTU feedback and skip node addresses with explicitly unavailable routes.
- Save successful measurements locally per node and network; matching starts reuse them without probe traffic.
- Keep a conservative fallback and an optional manual override. See [TUN MTU configuration](../tun-mtu.md).

## Build fixes

- Match transport initialization to the current configuration schema and pass the complete Rust formatting check.
- Use an explicit Intel macOS runner for Intel CI, packages and release assets.

## Validation

The update fixes passed recovery, configuration-protection and Web UI status tests. The same fixes were tested on an ARM64 Merlin router in a development build labelled v0.0.15. Startup MTU selection and cached reuse were also exercised on an ARM64 Merlin router. Release binaries are built by the tagged release workflow.

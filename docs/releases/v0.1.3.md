# v0.1.3

Sockrocket shares one native Rust engine across desktop, CLI and AsusWRT-Merlin.

## Protocols and compatibility

- Add native AnyTLS v2 with bounded TLS session reuse and UDP-over-TCP v2.
- Add single-peer userspace WireGuard with preshared keys, tunnel DNS, AllowedIPs validation and bounded flow/socket resources. No external proxy core is required.
- Import and persist the new protocols through share links, Clash and sing-box configurations; support single-peer WireGuard profile import and Merlin manual entry.
- Preserve Hysteria2 URI authentication and SNI, and sing-box REALITY transport settings.
- Reject unimplemented Vision, gRPC/XHTTP and legacy non-AEAD VMess instead of silently changing the requested protocol.
- Keep WireGuard UDP within tunnel MTU; multi-peer profiles, IP fragmentation and configuration scripts are not supported. See [protocol support](../protocols.md).

## Stability and interfaces

- Preserve physical-route recovery, DNS validation and proxy cleanup behavior.
- Retain WireGuard port leases while TCP connections drain; bound queues and socket retention, prevent replacement of live sockets, and reset shared handshake rate limits.
- Preserve Merlin manual stop during configuration and subscription updates; keep fail-open DNS and transparent-proxy recovery checks.
- Integrate the settings interface into Merlin's management page and add a sanitized actual-interface capture to the website and documentation.
- Redact protocol credentials from Debug output and keep local diagnostics, credentials and runtime state outside the public source tree.

## Validation and limits

Core and CLI regressions, independent AnyTLS/WireGuard interoperability, Merlin fault-injection tests and ARM64 cross-compilation are covered. Desktop and router build artifacts are produced by GitHub Actions. Long-running low-memory hardware tests and protocol modes listed as unsupported remain outside these guarantees. Interoperability reference executables and local diagnostics are not included in release packages.

# v0.1.3

- Refresh the desktop interface with macOS settings styling and clearer rule editing.
- Preserve the physical IPv4 route when enabling macOS TUN to restore direct connections.
- Harden DNS validation, TCP fallback, TTL handling and runtime cache isolation.
- Add bounded native UDP associations for supported proxy protocols. ShadowTLS UDP remains unsupported.
- Authenticate the local management API and make configuration writes atomic.
- Fix Merlin RPC dispatch and subscription updates; opening settings and editing configuration preserve manual stop.
- Probe DNS answers before taking over LAN DNS and recover to direct networking on failure.

Router deployment and local protocol checks have been performed. Long-running low-memory hardware stress and macOS IPv6 route ownership still require further validation.

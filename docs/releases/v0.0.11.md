# v0.0.11

## Memory

- Consumed TCP, TLS, and frame bytes are dropped when they are read or acknowledged, instead of keeping the allocation until the flow closes.
- TUN TCP shares one payload budget across flows for unread receive data and unacknowledged send data.
- WebSocket data frames stream into the caller buffer instead of reserving the full declared frame size first.
- TUIC sets a connection-level QUIC receive window so concurrent streams cannot grow without bound.
- Merlin can recycle a large proxy after a memory fail-open, once live flows have had time to drain.

## DNS

- The Merlin dnsmasq postconf helper publishes through a private temp file and rename, so overlapping runs do not truncate the live config.

# v0.0.9

## Merlin

- Merlin 3006 main DNS isolation no longer depends on a `servers-file` line. Guest and SDN resolvers stay on the firmware upstream.
- A QUIC path that stays slow is replaced instead of being reused until restart.

## Subscriptions

- Subscription downloads try the WAN first and use the local proxy only if that fails.
- Distinct remarks that share one endpoint stay in the node list.

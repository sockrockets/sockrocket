# README illustrations

These are documentation illustrations based on the project's Figma design direction and its companion vector layouts. They are not captures of a running proxy client and do not claim pixel parity with a release. Feature availability is described in the main README and the current application.

- `overview`: connection overview and traffic capture controls.
- `nodes`: node selection and subscription sources.
- `rules`: rule conditions and editing actions.
- `rules-bulk`: text entry, validation and confirmation.

Each PNG has an editable SVG source. All node names, subscription names, latency and traffic figures are fictional. Domains use the reserved example.com / example.org / example.net namespaces; the example CIDR is the documentation range 192.0.2.0/24. No production endpoints, personal paths, account details, subscription tokens, QR codes or live screenshots are included. PNGs are rendered from these SVGs without retaining source metadata.

When updating these illustrations, use synthetic data from the outset. Do not substitute screenshots from a personal configuration, even if some fields are blurred.

# Sockrocket · macOS 设置风格设计

打开 [index.html](index.html) 体验交互原型。页面是本地静态设计演示，不会请求订阅、创建代理服务、修改系统网络或调用管理员权限。数据与检查更新结果均为示例。

## 交付物与状态

- `index.html`：9 个主分类，中文界面，浅色与深色，主要详情、表单与异常状态。
- `overview.svg`：15 个页面/状态的总览（含规则详情、批量编辑和网络诊断）；`figma-svg/` 为可逐个导入 Figma 的独立 SVG。图形由文本、路径和形状组成，无界面截图填充。
- `export_figma.py`：重新生成 SVG，不依赖第三方库。
- `check-prototype.cjs`：无依赖的脚本冒烟检查。运行 `node check-prototype.cjs`。
- [Figma 草稿](https://www.figma.com/design/VxFaQKdF8IMrD7i5qipEpn)：已创建本地组件与 12 个页面，**未完成，不能作为验收稿**。Starter 账号调用额度耗尽前发现组件宽度与内容高度问题，尚未修好，也尚未建立点击跳转。

Figma 官方 macOS 库导入被账号权限拒绝。SF Pro 在该 Figma 环境中被标记为缺失，云端稿使用 Noto Sans SC 临时替代。本地原型优先使用 macOS 系统字体与苹方，图标复用项目现有 SVG。恢复插件额度后，可先修复云端稿布局与组件尺寸，再同步本地完整页面和交互；也可手动把 `figma-svg/` 文件拖入 Figma 继续编辑。

## 竞品研究后的第二版

完整调研、依据与能力边界见 [RESEARCH.md](RESEARCH.md)。本轮参考 Clash Verge Rev、Surge、Hiddify、sing-box 的官方资料；没有安装竞品实测。

首页区分服务与接管，加入当前模式/节点路径、紧凑指标与分步诊断；节点增加组合筛选、收藏、排序、来源和测试时间；订阅支持独立更新；策略组展示类型、当前出口和成员，改名同步规则引用；规则支持最近一次撤销，批量编辑保留原启用状态。浅色、深色和窄窗口控件层级统一。上述交互都只修改原型内存状态，未接入生产内核。

本轮新增脚本检查覆盖来源筛选、收藏、策略选择、服务/接管差异、撤销、配置取消恢复、组改名引用迁移与单独订阅更新。概览与节点 SVG 已重新渲染检查；未执行浏览器端到端验证。

## 核心交互约定

### 规则列表本轮完善

- 列表直接展示单条规则的全局优先级、匹配值、类型、出口和启用状态；分组可展开收起，支持关键词与状态筛选。统计来自实际示例条目，不再使用虚构的 120/32 条数量。
- 点击匹配内容查看详情，独立编辑按钮修改单条规则；支持上移、下移、启用/关闭、删除确认。单条保存会验证域名、CIDR（含 IPv6）、GeoIP、端口区间和有效出口，并阻止重复匹配条件。
- “批量粘贴”追加规则；分组的“批量编辑”预填原规则文本并替换该分组；勾选多条后可以批量启停、删除或编辑。所选项编辑明确显示保存后的目标分组。
- 批量流程为文本编辑 → 校验预览 → 确认保存。保留原始文本，错误标注行号、原文和原因，可返回修正；任何错误都会阻止保存。预览展示有效条目、新增、覆盖和跳过数量，确认前不修改已保存规则。
- 支持空行、`#` / `//` 整行注释、`PROXY` / `DIRECT` / `REJECT` 和已有策略组名称。重复按“类型 + 匹配内容”识别，可选跳过或覆盖；已有匹配条件保留启用状态，新增规则默认开启，界面明确提示。
- `MATCH` 只更新列表底部的默认出口，不生成普通规则；最多一条且必须位于最后。导出包含启用规则与最终出口。
- 取消有修改的批量草稿时确认放弃；原型仍只保存在内存中，刷新页面恢复示例。脚本检查覆盖实际解析、范围替换、重复策略、优先级及保存行为；未执行真实浏览器端验证。

1. 首次使用：添加链接/文件 → 格式校验 → 导入预览与重复项处理 → 节点列表 → 选择节点 → 连接。原型预览数量固定为示例，真实结果必须接内核解析器。
2. 连接：未连接 → 连接中（可取消）→ 成功/失败。失败给出重试、换节点、网络设置和日志入口。断开/失败时恢复原系统代理；正式实现必须保存并恢复原值，而非简单清空。
3. 切换节点：单击节点即选中，影响后续新连接。详情按钮独立，避免查看信息时误切换。
4. 普通偏好立即生效；监听地址/端口等网络参数采用“编辑 → 校验 → 应用”。离开页面时提示未保存更改。实际应用失败时保留草稿和旧监听，并显示错误。
5. 更新订阅保留旧节点；新结果通过解析与校验后再替换。界面显示来源未提供的流量/到期数据，不推测数值。
6. 删除节点、删除订阅、清空日志明确影响范围。订阅删除需在正式实现中提供保留或移除来源节点的选择。
7. TUN 在详情中说明接管范围，再触发系统授权；失败/拒绝不显示“已开启”。局域网访问开启时解释监听范围变化。
8. 分享使用内核生成的真实 URI、二维码与带令牌订阅。原型仅提供演示链接，不生成可用凭据或伪二维码。

## 二级表单的实现要求

原型的节点详情展示通用字段。正式实现需按协议和传输方式动态显示字段，并复用 `config/model.rs` 与现有导入导出逻辑，避免把不支持的组合暴露给用户。

| 协议/功能 | 必要字段与状态 |
| --- | --- |
| Shadowsocks | 服务器、端口、加密算法、密码、UDP、可选 ShadowTLS 配置 |
| VMess | UUID、加密方式、TLS、传输；保持内核支持的实际组合 |
| VLESS | UUID、flow、TLS/Reality、传输；条件显示相关参数 |
| Trojan | 密码、TLS SNI、证书校验、传输 |
| TUIC | UUID、密码、TLS、拥塞参数；仅显示内核可用字段 |
| Hysteria2 | 认证、TLS、混淆和带宽配置；只开放已支持项 |
| 传输/TLS | 按模型显示 TCP / WebSocket 等选项、Host/path、SNI、ALPN、证书策略；不默认关闭证书校验 |
| 规则 | 类型与匹配值联动；MATCH 不需要值；GeoIP、CIDR、端口范围分别校验；引用失效策略时阻止保存 |
| 策略组 | 名称唯一、至少一个成员、无循环引用；移除正在被规则引用的组需提示引用位置 |
| DNS | 解析模式、上游、Fake IP 范围、缓存统计与清理；保存时检查模式兼容性 |
| 配置 | 原型仅检查 JSON 与端口；正式版须完整反序列化、语义校验、备份及失败回滚 |

## 视觉与可访问性

- 246px 分类侧栏；主内容使用分组列表、细分隔线和低对比背景，系统蓝仅用于选中与主操作。
- 13px 正文、22px 标题；状态同时使用文字与图标。端口、流量和日志可用等宽数字。
- 浅色：背景 `#f5f5f7`、面板 `#ffffff`、侧栏 `#eaeaf0`；深色对齐项目 `theme.rs` 的深灰底与系统蓝。
- 提供键盘焦点、搜索标签、开关语义、弹窗标题、Escape 关闭与状态播报。正式应用应把紧凑开关的可点击区域扩展到整行，并支持系统字号与减少动态效果。
- 连接展示以现有 `ConnectionRecord` 为准，不虚构进程归属、实时逐连接流量或内核未实现的强制断开功能。

## 已验证与限制

脚本检查覆盖 9 个页面、18 类弹窗、连接状态切换、节点选择、端口范围/冲突和未保存更改，并补充规则解析与批量编辑检查。15 个 SVG 使用可编辑图形与文本；概览及新版规则列表已渲染检查。

浏览器工具拒绝访问 `file://`，因此未执行真实浏览器视觉与端到端验证。本地 HTML 的状态检查不等同于浏览器验证。云端 Figma 当前也未通过验收。设计原型没有修改 GPUI 生产界面，所有模拟操作仅存在页面内存中。

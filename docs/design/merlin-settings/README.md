# Merlin 内嵌管理界面

[Figma 可编辑设计与交互原型](https://www.figma.com/design/LiC2GFiBYkduLXN67uWwqI)

设计包含概览、节点、订阅、分流规则、诊断、节点详情及手机视图。保留 Merlin 固件顶部栏和主菜单，Sockrocket 在内容区内使用横向页签，不使用 iframe 或独立站点。插件内容采用 macOS 系统设置的浅色分组面板、明确的状态和操作。

## 交互约定

- 概览区分服务进程状态、路由器探测与局域网设备验证；进程运行不等于所有设备联网正常。
- 查看节点详情不会切换节点；切换有明确按钮，接口失败时保留原节点。地址默认隐藏，主动选择后才展示。
- 订阅与高级配置包含敏感数据，不进入设计稿。所有 Figma 数据均为虚构示例。
- 高级配置保存期间防止重复提交，重新加载前提示未保存修改；后台加载不覆盖新的编辑。
- 日志支持级别筛选与隐藏连接重置噪声，清空日志和重启需要明确确认。隐藏页面暂停状态及日志轮询。
- 手机端使用横向页签、两列指标和单列设置卡片。

## 实现与验收状态

`merlin/webui/sockrocket.asp` 已改为固件外壳候选实现：加载固件自身样式与导航脚本，使用 TopBanner/mainMenu/subMenu/tabMenu/footer 挂载点，插件样式限定在自己的根节点内。保留现有 HTTP、CGI 和软件中心 RPC 传输。

Figma 使用本地可编辑组件和语义变量；官方 macOS 组件库无法导入，未冒充官方组件。页面导航、主要操作、空状态及错误提示已改为中文；协议名称、规则格式、服务端返回的消息保留原文。

已通过脚本语法、现有传输回归、HTML 嵌套/标签关联检查和离线交互检查：失败切换不改节点、私有地址主动展示及关闭清理、配置编辑竞态、规则预览快照、重复操作拦截、轮询在途上限及隐藏暂停。测试使用虚构数据，临时交互检查脚本位于忽略目录 `.local/`。尚未部署；固件版本间导航兼容性、菜单入口及真实浏览器视觉与操作仍需路由器实机验收。标准 Merlin 的 ext 页面复制不等于原生菜单注册，安装器的菜单注册仍待适配；软件中心保留现有 Module_sockrocket.asp 入口。本次没有修改运行中的路由器或本机网络。

固件布局参考：[Asuswrt-Merlin 原生页面源码](https://github.com/RMerl/asuswrt-merlin.ng/blob/main/release/src/router/www/Advanced_VPNClient_Content.asp)。

## 代码审查修复

已修复本轮审查确认的四项问题：

- 控件隐藏：隐藏规则仅匹配 `[hidden]`，按钮、输入框和下拉框恢复正常样式；增加针对标签级隐藏的 CSS 静态回归检查。
- 停止优先：启动/重启尚未完成时仍发送 Stop；重复 Stop 合并。较早请求的回调不会覆盖较新停止请求的反馈，所有在途生命周期请求完成前保持忙碌状态。
- 规则导出：独立只读结果框与复制按钮，不再清空或复用规则编辑器；请求失败可重试。
- 配置读写：保存期间阻止新读取，保存使较早读取失效，多次读取仅采用最新请求结果；失败保留草稿和正确的未保存状态。

以上修复通过乱序响应、失败重试、草稿保留及 CSS 选择器静态回归检查；原有传输与离线交互检查仍通过。临时专项脚本在忽略目录 `.local/`，没有加入发布包。CSS 静态检查不能代替真实浏览器视觉验收，本轮未部署路由器。

## 实际浏览器验收补充

已使用浏览器登录路由器，实际打开软件中心中的 Sockrocket 页面，检查概览、节点、订阅、规则与诊断页；节点详情默认隐藏服务器地址，订阅列表隐藏 URL，规则导出显示独立结果框。只读诊断显示服务、配置、DNS、dnsmasq 与防火墙状态正常；没有执行切换节点、停止、重启或保存配置。

390 像素窄屏测试发现固件顶栏/页脚中的定位元素把文档撑宽至约 982 像素。已为这两个区域建立定位边界并仅更新 ASP 文件；复测文档宽度 386 像素、插件宽度 370 像素，订阅与规则表单正常显示。测试后已恢复浏览器默认尺寸，保留概览页供查看。验收局部图保存在本机忽略目录，未含订阅地址或节点信息。

当前内核尚未提供 `health.runtime` 连接计数，界面按设计显示不可用提示，没有伪造数字。诊断日志中看到 UDP 接收队列饱和丢包告警，仍需单独调查，不能把界面验收通过当作长期网络稳定性结论。

# 隐私保护

这里写清两件事：软件在本机保存和发出什么，以及提交、标签、反馈里什么算个人信息。

## 什么算个人信息

- 真实姓名、个人邮箱、个人代码托管账号
- 电脑主机名、操作系统用户名
- 某一台机器的局域网地址、账号、非默认端口，以及能单独认出这台部署的路径
- 密码、订阅完整地址和查询参数、节点地址、UUID、令牌、私钥、二维码里的凭据

提交说明、作者、提交者、标签标记者、附注，以及仓库里的文件，都不要写这些。

## 什么不算个人信息

下面这些可以留在历史和文件里：

- 项目身份：`Sockrocket` / `sockrockets@users.noreply.github.com`
- 托管平台替合并提交写下的 `noreply` 地址，例如 `noreply@github.com`
- 其他明确的 `noreply` 地址
- 测试和文档里的示例网段、保留地址、公共 DNS 地址，以及内置的中国地址段
- 上游许可证里的第三方版权声明

`noreply` 地址不标识一个人，也不标识一台电脑。

## 提交和标签

作者、提交者和标签标记者使用上面的项目身份。不要改本机的 git 配置。如果当前身份是个人姓名、个人邮箱或主机名，只在这一次命令里覆盖：

```bash
git var GIT_AUTHOR_IDENT
git var GIT_COMMITTER_IDENT
```

任一结果包含个人姓名、个人邮箱或主机名时：

```bash
GIT_AUTHOR_NAME=Sockrocket \
GIT_AUTHOR_EMAIL=sockrockets@users.noreply.github.com \
GIT_COMMITTER_NAME=Sockrocket \
GIT_COMMITTER_EMAIL=sockrockets@users.noreply.github.com \
git commit -m "$(cat <<'EOF'
Commit message here.

EOF
)"
```

说明只写改了什么。`Fix DNS upstream selection` 这样的主题就够了。

不要在说明或附注里写：

- `Signed-off-by`、`Co-authored-by`，以及其他点名一个人或一个邮箱的附注
- 局域网地址、账号，或能指纹识别一台机器的路径

已经发布的历史，只有在明确要求时才改写。

## 不要提交的本地文件

- `.local/` 整目录，包括路由器环境、登录笔记和本机部署记录
- `.cursor/` 整目录
- 真实密码，以及只属于这一台机器的地址和端口

`.local.example/` 只保留空占位：`ROUTER_HOST` 和 `ROUTER_PASS` 留空，`ROUTER_PORT` 用 `22`。

## 软件在本机保存什么

配置、配置备份、运行日志和崩溃记录默认使用私有权限（`0600`，服务脚本的 umask 是 `077`）。管理 API 只监听 `127.0.0.1`，并要求本机的 Bearer 令牌。浏览器通过固件的管理入口访问，不把这个 API 直接开到局域网上。

默认日志级别是 info。只有设置了 `SOCKROCKET_LOG_FILE` 时，日志才升到 debug 并写入该文件。Merlin 启动不会设置这个变量。

订阅刷新的请求文件放在 `0700` 目录里的 `0600` 文件中，工作进程读完就删。流量账本记录的是字节计数。Web 界面给出连接数量，不给出目的地列表。

Merlin 3006 上，主局域网的上游写在单独的解析文件里，权限是 `0644`，因为固件里的 dnsmasq 要以非 root 身份读取。内容只有指向本机监听端口的 `server=127.0.0.1#端口`。访客网络和 SDN 继续用固件自己的解析文件，不会改成这个文件。

`config.yaml`、它的备份，以及 Web 界面的高级配置，会保存完整的节点凭据。不要把这些文件、管理页的开发者工具记录或完整诊断附件交给别人。轮换令牌后，按需删掉仍含旧凭据的备份。

## 仍然存在的网络暴露

订阅地址如果是 `http://`，路径上的观察者可以读到访问令牌和返回的节点凭据。能用 HTTPS 时就换 HTTPS，并轮换曾经在 HTTP 上用过的令牌。

Merlin 模板里的代理监听默认是 `0.0.0.0`，SOCKS5 不做认证，这样局域网里的客户端才能连上。只用透明代理时，可以把监听改成 `127.0.0.1`。需要局域网显式代理时，用路由器防火墙限制到可信设备。

## 反馈和截图

桌面设计图用虚构数据。Merlin 界面截图在导出前去掉可识别信息。提交 Issue、讨论、日志或截图之前，去掉订阅完整地址、查询参数、节点地址、密码、UUID、令牌、二维码、个人路径和账户信息。二维码和分享链接里也可能有完整凭据。

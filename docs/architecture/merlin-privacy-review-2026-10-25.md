# Merlin 分支隐私复审 — 2026-10-25

范围：`main...fix/merlin-review-followups` 的代码变更，并追踪配置、订阅、节点凭据从浏览器和下载器到存储、日志与网络监听的路径。本轮只使用本地代码、合成测试数据和 Git 差异；没有连接真实路由器或请求用户提供的订阅。功能复审未发现新的可复现回归；Rust CLI/Core 测试、Merlin 安装和网络策略模拟测试通过。真机固件行为仍以 [兼容性说明](merlin-compatibility.md) 中的验收项为准。

| 结论 | 证据与处理 |
| --- | --- |
| 已修复：配置及升级备份可能继承较宽的文件权限 | `install.sh` 原先直接复制配置模板及现有配置到 `config.yaml.bak`，未明确收紧权限。现对现有配置和备份执行 `0600`，用私有 umask 创建新配置/备份，并拒绝指向其他文件的备份符号链接；安装测试覆盖全新安装、旧 `0644` 文件升级和符号链接。备份仍保留旧凭据，轮换令牌后应按需删除旧备份。 |
| 已确认：管理 HTTP API 不直接暴露在 LAN | `cgi/http.rs` 只绑定 `127.0.0.1`，要求私有 `api-token` 的 Bearer 令牌。浏览器使用固件 CGI / 软件中心 RPC；订阅地址和完整配置只在管理功能中返回，WebUI 默认遮住订阅地址，显示和复制需显式操作。模板中误称浏览器可直连路由器 API 的旧注释已纠正。固件登录、HTTPS 配置和其他插件的权限仍属于路由器环境。 |
| 已确认：后台任务与统计的本地范围 | 订阅请求文件写入 `0700` 目录、`0600` 文件，工作进程读取后删除；结果文件和流量账本由私有原子写入保存。作业在领取请求前异常退出时，私有请求文件可能保留到下一次状态查询/任务清理；这属于剩余的本地数据留存边界。 |
| 剩余网络风险：明文 HTTP 订阅 | 为兼容现有供应商，订阅下载同时接受 `http://` 和 `https://`。HTTP 请求中的访问令牌和响应中的节点凭据可被路径上的网络观察者读取或篡改；软件无法替供应商补 TLS。能使用 HTTPS 时应更换为 HTTPS 地址，并轮换曾经通过 HTTP 传输的令牌。 |
| 剩余 LAN 风险：代理端口默认开放 | Merlin 模板的 `listen_addr: 0.0.0.0` 使 SOCKS5/HTTP 代理可供可达该路由器端口的设备使用，SOCKS5 使用无认证协商。这是兼容局域网代理客户端的现有行为。若只使用 TUN 透明代理，可将监听改为 `127.0.0.1`；需要 LAN 显式代理时应通过路由器防火墙限制可信设备/网段。 |

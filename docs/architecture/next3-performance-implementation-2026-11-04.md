# TUN 队列、DNS 合并和 TLS 依赖裁剪

日期：2026-11-04。三项已实现并通过验证，采用 fat LTO、保留 opt-level=3 的候选已部署到路由器。opt-level=s 的体积候选未部署。

## 实现

1. TUN 包队列释放预算时，无已登记的待唤醒任务即可跳过等待队列锁。曾经阻塞但已经恢复的发送者不会永久关闭这条快速路径；一次完整扫描没有发现待唤醒任务就恢复跳过检查。登记、设置 waker 与快速路径标记在同一把预算锁下串行，避免登记和释放并发时丢失状态。
2. 原始 DNS 查询在缓存未命中时合并相同的在途交换。只归一化事务 ID，保留报文的大小写、类型、标志和 EDNS 差异；按直连意图、所选上游集合及出站身份隔离，运行时配置代际使用独立映射。每个响应恢复调用者自己的 ID。取消初始化者后其他等待者能重新初始化，最后一个调用者退出时同步移除条目；上游 JoinSet 不脱离请求生命周期。归一化键大于 512 字节或条目达到配置容量（限制在 16–1024）时不新增合并条目，走原有受监听器准入约束的路径。
3. 现代 rustls 和 tokio-rustls 关闭默认功能，显式保留 ring、TLS 1.2、std（rustls）和日志。生产 CLI 依赖图不再引入 aws-lc。ML-KEM/HRR 独立服务端测试仍通过 core 的开发依赖启用 aws-lc；resolver v2 将其与生产图隔离。原有 craftls 指纹、REALITY 和 ML-KEM 实现没有裁剪。

## 验证

- 完整离线运行时回归：817 通过、0 失败、21 忽略。
- 新增 DNS 测试确认 20 个并发查询只产生 1 次上游交换，且保留各自事务 ID；覆盖取消初始化者、最后调用者取消、后续非并发查询重新访问上游，以及 flags/EDNS/类型/出口/上游集合的隔离。
- 新增队列测试覆盖快速路径恢复、重新登记无重复条目，以及 200 轮登记/释放竞态；原有公平唤醒、取消和信用返还测试通过。
- 生产依赖图 `cargo tree -p sockrocket-cli --offline -e features,no-dev` 无 aws-lc 或 prefer-post-quantum。独立普通依赖程序没有启用 core 的开发依赖，TLS 1.2、TLS 1.3 和项目生产 QUIC 客户端的握手与数据往返均通过，避免测试依赖重新启用后端而掩盖发布问题。
- sing-box 预热/非预热 Vision 互通：2 通过。
- 标准 ARM64 构建通过，musl 分配器验证通过，Zig SMP 符号为零；`git diff --check` 通过。

记录及标准候选位于 `.local/next3-performance-20261104/`。标准候选 SHA-256：`1a19c8b6ac1293ad99b3d412b0843bccd7b82aaf85d3e342e300a1a30ac6cc18`，15,092,032 字节，比上一部署版本增加 26,656 字节。本轮三项合计没有带来标准参数下的净体积缩减，不能把减少构建依赖直接等同于最终二进制变小。

## 体积实验与分配器约束

所有体积实验均通过 `tools/build-merlin-musl.sh` 构建，最终链接仍是 Rust 的 `rust-lld` 与 `-C link-self-contained=yes`；Zig 仅编译 C 依赖。每个完成的实验产物都在剥离前检查 musl 分配器及 Zig SMP 符号，另存 symbols 文件。不能为了体积切回 Zig 最终链接。

当前已完成的相同源码比较：

| 参数 | stripped 字节 | MiB | 单文件 gzip-9 字节 |
| --- | ---: | ---: | ---: |
| opt-level=3，thin LTO | 15,092,032 | 14.39 | 7,029,067 |
| opt-level=3，fat LTO | 14,209,032 | 13.55 | 6,824,871 |
| opt-level=s，thin LTO | 12,267,024 | 11.70 | 5,418,538 |

`s` 版本缩小 18.72%，SHA-256：`a018c912e445554e6f7c8f360b34123bd215e07b62d1d76af5803d690587b6a3`。gzip 数字只是对单个可执行文件的压缩测量，并非完整安装包大小。实验记录位于 `.local/size-experiments-20261104/`。

构建命令：`CARGO_PROFILE_RELEASE_OPT_LEVEL=s bash tools/build-merlin-musl.sh`。没有修改默认发布参数。该体积版本尚未做路由器吞吐、CPU 和内存对照，不应据大小直接替换当前部署。

单独改用 fat LTO、保留 opt-level=3，也缩小了 5.85%，SHA-256：`b320e53a596471a915475d44632f31fd83d141e1e60c9e2fc7a20e4604e1aa01`。命令：`CARGO_PROFILE_RELEASE_LTO=fat bash tools/build-merlin-musl.sh`。分配器验证通过，已部署并完成下述短时检查。它没有改变优化等级，但仍不能仅凭编译参数保证吞吐不变。

符号检查还发现 Brotli 编码器及其静态表进入产物。项目客户端使用无客户端证书认证的 TLS 配置，可继续研究只保留证书解压能力的客户端 provider，保留所宣告算法和指纹；当前没有实现或计入其预计收益。

用户授权后部署到 RT-AX86U Pro。安装文件为 14,209,032 字节，比上一实际部署版本（15,065,376 字节）减少 856,344 字节，即 5.68%。同源码构建参数实验的 5.85% 使用的是本轮标准候选作为基线，两者不可混淆。

新旧各五轮 SOCKS/TUN 请求与 1 MiB 下载，每版 30/30 成功。成功样本总耗时中位数（秒）：
